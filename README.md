One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer. Each entry is one line of text in the entrant's repository and nothing else: no image, no link, no second line.

## Run it

```sh
node main.ts
```

It writes the entry line to `/output/entry.txt`, self-checks the gate (one line, 1–200 characters, no control characters, no edge whitespace), reads it back with strict UTF-8 decoding and verifies it byte-for-byte.
